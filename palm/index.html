The Song, Not the Pin

The obvious fix for shared memory is to send the full route, not just the destination. But a correct route is not permission to act. It covers one of five use conditions; the other four must travel with it.

1. The obvious fix: send the full route. Is that enough?A sends B a correct route to the water. Untick a condition and press Go.

Record from agent ARoute to water: up, along the top, downcorrect route

The route only answers “how do I get there?”. The other four conditions must travel with the record too.

2. What to send depends on the receiverTap cells to add or remove walls.

Routes are not new. The point is the receiver: a robot that cannot plan needs the route, while a robot that can plan is fine with the pin and only takes longer. Switch “B can plan around walls” to see both.

3. Who gets the water?4 agents, 2 water sources. Everyone hears about both.

Everyone already knows where the water is, so better information does not help here. Coordination does: with claims, the closer agent keeps the target and the others go elsewhere.

4. When does a record expire?A record is used while trust × confidence × fading stays above a cut-off.

Expires after

agemax = (1/fade) · log(trust × confidence / cut-off). In the paper, every expiry predicted this way matched the experiment exactly.

What is new here?

Each mechanism exists on its own: routes in robot planning, reservations in multi-agent planning, expiry in caches, map alignment in robotics. The paper joins them into one contract for shared memory and shows that each condition is needed on its own: break any one, and a correct record leads to failure.

Limits: mostly simple grid worlds; the LLM test is small.

Paper: Zamotaev, Gusarova, Tomilov, Vatian. The Song, Not the Pin: Provenance-Conditioned Route Memory for Persistent Multi-Agent Navigation. ITMO University.
