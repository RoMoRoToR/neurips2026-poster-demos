Which stage broke?

An agent must fetch a key in a four-room house. A success score only says whether it failed. Q/R/M/C reads four events from the agent's log and finds the stage that broke.

QQuery: did it ask its memory?
RRetrieval: was the right record returned?
MMaterialization: did it commit to the true place?
CCompletion: did it get the key?

1. Break the agentPick one fault. The diagnosis does not see your choice.

2. Read the diagnosisEach stage is compared with a healthy agent. The first stage that drops below the line is the diagnosis.
